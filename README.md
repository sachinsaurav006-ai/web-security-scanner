
# Automated Web Security Scanner

## About
A beginner-friendly Python project that checks basic website security configurations.

## Features
- HTTP status check
- Security header audit
- Cookie security flag checks
- Basic CORS configuration check
- Terminal security report

## Technologies Used
- Python
- Requests Library
- HTTP and HTTPS

## Installation

Install the required library:

```bash
python -m pip install requests
```

## How to Run

```bash
python scanner.py https://example.com
```

Only scan websites you own or have permission to test.

## Disclaimer
This project performs basic security configuration checks. It is not a complete vulnerability scanner.
